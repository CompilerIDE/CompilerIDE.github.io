## 产品简介
本 IDE 由 CompilerIDE Team 共同开发，支持的编程语言只有 C++。目前最新版本为 $3.7.0$。操作系统应为 Windows + 64 位操作系统（不支持 Win7 及更低版本）。

截至目前，本 IDE 支持如下功能：
- [x] 一键编译运行
- [x] 代码修改
- [x] 深色模式和浅色模式切换
- [x] 自动括号补全
- [x] 自动缩进
- [x] 可选择编译器路径
- [x] 支持查找、替换功能
- [x] 支持放大、缩小功能
- [x] 拥有项目管理器功能
- [x] 可自动查找编译器路径并自动配置
- [x] 支持在 IDE 内下载编译器
- [x] 拥有比赛模式
- [x] 代码补全
- [x] 诊断工具、终端、代码片段
- [x] 临时编译、临时编译运行
- [x] 数据评测器
- [x] 洛谷题目爬取器
- [x] DeepSeek AI 助手
- [x] 对拍器
- [x] 代码美化等

下列功能将会在后续版本中支持：
- [ ] 基于上下文的智能代码补全
- [ ] 支持查看算法教程
- [ ] 增加对 MacOS 和 Linux 系统的支持
